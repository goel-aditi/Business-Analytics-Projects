# Advertising Data Clustering Analysis

## Project Overview

This project analyzes advertising campaign data using exploratory data analysis and clustering techniques to identify meaningful patterns across campaigns.

The objective was to understand differences in campaign performance based on metrics such as impressions, clicks, CTR, CPM and CPC, and to identify groups of campaigns with similar characteristics.

## Business Problem

Advertising campaigns can generate large volumes of performance data. Analyzing this data manually can make it difficult to identify patterns and understand which campaigns behave similarly.

This project uses data analysis and clustering to segment campaigns based on their performance characteristics.

## Dataset

The dataset contains advertising campaign performance data with variables related to impressions, clicks, cost and engagement.

## Analysis Performed

- Data cleaning and preprocessing
- Exploratory data analysis
- Descriptive statistics
- Data visualization
- CTR, CPM and CPC calculation
- Feature scaling
- K-Means clustering
- Cluster evaluation using silhouette score
- Cluster-wise performance analysis
- Business interpretation of the clusters

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Excel
- Jupyter Notebook

## Key Outcomes

The analysis identified distinct groups of advertising campaigns based on their performance characteristics.

The clusters were further analyzed using metrics such as CTR, CPM, CPC and device-level performance to understand differences between campaign segments.
