# Sports Performance Classification using Decision Tree

## Project Overview

This project uses a Decision Tree classification model to analyze sports-related data and identify patterns associated with the target outcome.

The analysis focuses on understanding relationships between the input variables and the target variable and developing a classification model using machine learning.

## Business Problem

The objective is to use historical sports data to identify patterns in the target outcome and understand which variables contribute to the classification.

## Dataset

The dataset contains sports-related observations and variables used to build and evaluate a classification model.

## Analysis Performed

- Data cleaning and preprocessing
- Exploratory data analysis
- Descriptive analysis
- Feature identification
- Train-test split
- Decision Tree classification
- Hyperparameter tuning
- Model evaluation
- Training and testing performance comparison
- Interpretation of decision tree results

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Model

A Decision Tree Classifier was developed using Scikit-learn.

Key hyperparameters considered included:

- Maximum tree depth
- Minimum samples split
- Minimum samples leaf
- Splitting criterion

The model was evaluated using appropriate classification performance metrics on training and testing data.

## Key Outcomes

The project demonstrates how machine learning classification can be used to identify patterns in sports data and evaluate the factors associated with the target outcome.
