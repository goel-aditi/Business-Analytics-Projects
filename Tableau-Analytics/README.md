# Tableau Analytics Dashboard

## Project Overview

This project uses Tableau to analyze business data and present key insights through an interactive dashboard.

## Tools Used

- Tableau
- Excel
- Data Visualization
- Dashboarding

## Project Objective

The objective was to analyze the dataset, identify important trends and patterns, and communicate the findings through an interactive Tableau dashboard.

## Key Areas

- Data analysis
- KPI tracking
- Trend analysis
- Interactive visualizations
- Business insights

## Files

- `tableau_dashboard.twb` – Tableau workbook
- `tableau_dataset.xlsx` – Dataset used for the analysis
